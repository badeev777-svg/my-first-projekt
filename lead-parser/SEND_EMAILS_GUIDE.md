# 📧 Инструкция: Как отправить письма 30 веб-студиям

**Файл:** `web_studios_contacts.csv`  
**Письмо:** Используй текст из `SALES_EMAIL.md`

## 🚀 Способ 1: Gmail Mail Merge (автоматический, рекомендуемый)

1. **Открой Google Sheets** → создай новую таблицу
2. **Скопируй контакты из CSV** в Sheet:
   - Колонка A: Studio
   - Колонка B: Email
3. **Установи расширение** "Gmail Mail Merge" или "Yet Another Mail Merge"
4. **Создай письмо в Gmail** с шаблоном:
   ```
   Привет, {{company}}!
   
   Мы собираем и анализируем заказы с FL.ru, Kwork, Habr в реал-тайме через AI.
   Ты первым видишь релевантные проекты и отправляешь предложение быстрее конкурентов.
   
   Цена: 1000₽/месяц за бота с уведомлениями.
   
   Demo: http://155.212.208.194:8000/leads/
   
   Пиши в ответ или в TG: @CowboyAleksandr
   ```
5. **Запусти рассылку** → письма отправятся автоматически

## 🚀 Способ 2: Ручная рассылка (простой)

1. **Открой CSV в Excel**
2. **Для каждого email:**
   - Создай новое письмо в Gmail
   - Скопируй текст из `SALES_EMAIL.md`
   - Заменить `[ИМЯ]` на конкретное имя (например, "Дмитрий" или "Команда ITECH")
   - Отправь
3. **Жди ответов** 24-48 часов

```

4. Ты отвечаешь первым — получаешь заказ раньше конкурентов

Результат за неделю:

- 30+ релевантных заказов (> 70% совпадение)

Хочешь попробовать бесплатно неделю? 
Покажу, как это работает.

Demo: http://155.212.208.194:8000/leads/
Telegram: @CowboyAleksandr
```

## 💡 Советы

1. **Не отправляй сразу всем** → лучше по 5-10 в день (спам-фильтры)
2. **Добавляй личные детали** → меняй имя в начале письма
3. **Отслеживай ответы** → отвечай быстро на вопросы
4. **A/B тестирование** → попробуй разные заголовки писем
5. **Follow-up** → если нет ответа через 3 дня → напомни

## 🎯 Целевые метрики

- **Open rate**: 20-30% (люди откроют письмо)
- **CTR**: 5-10% (перейдут на демо)
- **Conversion**: 1-3% (попросят полный доступ)

Если 1000 писем → ~150 откроют → ~50 на демо → ~5-15 заказов
