Parser — мастер по поиску заказов

Lead Parser — система автоматического поиска и фильтрации заказов.

Инструмент для автоматического сбора, фильтрации и управления лидами из Telegram, FL.ru и Habr Freelance. Сервис оптимизирует обработку заявок на разработку и продвижение сайтов, позволяя быстрее находить релевантные проекты.

Python / FastAPI / SQLite / Tailwind

Задача

Свести воедино заявки из нескольких источников, минимизировать ручной мониторинг и создать удобный веб-интерфейс для анализа лидов. Проект показывает умение строить end-to-end решение: от сбора данных до визуализации и управления статусами.

Решение

  • Асинхронный парсер для Telegram, FL.ru и Habr Freelance.
  • Автозапуск сбора заявок через APScheduler.
  • Хранение лидов в SQLite с асинхронным доступом через SQLAlchemy.
  • Веб-интерфейс на FastAPI + Jinja2 для удобного просмотра и фильтрации.
  • Статусы: новые, просмотренные, архив.

Что реализовано

Интерфейс показывает ленты лидов, позволяет фильтровать по источнику и статусу, а также сохраняет историю заявок.

При первом просмотре заявки автоматически помечаются как просмотренные.

Добавлен безопасный режим демонстрации без планировщика, чтобы можно было запускать сайт локально для презентации.

Проект легко расширяется: добавление новых источников, фильтров и уведомлений.

Результат

  • Сокращает время поиска потенциальных заказов.
  • Повышает прозрачность и контроль обработки лидов.
  • Демонстрирует навык разработки полного бэкенд- и фронтенд-решения.
