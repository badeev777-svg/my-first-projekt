## 📋 Инструкции по использованию

### Запуск приложения
```bash
docker run -d --name lead-parser-app -p 8000:8000 \
  --env-file .env.local \
  -v /path/to/data:/app/data \
  lead-parser
```

### Доступ
- **Веб-интерфейс:** http://155.212.208.194:8000/leads/
- **Demo анализ:** http://155.212.208.194:8000/leads/demo/
