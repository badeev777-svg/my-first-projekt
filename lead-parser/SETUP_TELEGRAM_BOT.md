# Настройка Telegram уведомлений для Lead Parser

Чтобы получать уведомления о новых лидах в Telegram, выполни следующие шаги:

## 1. Создай Telegram бота

1. Открой Telegram и найди бота `@BotFather`
2. Отправь команду: `/newbot`
3. Ответь на вопросы:
   - **Имя бота:** Lead Parser (или любое другое)
   - **Username бота:** lead_parser_bot_XXXX (должно заканчиваться на `_bot`)
4. BotFather вернет **BOT_TOKEN** вида `123456789:ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefg`

## 2. Получи свой Chat ID

Есть несколько способов:

### Способ А: Через бота (простой)

1. Создай группу или используй personal chat
2. Добавь твоего бота в эту группу (или напиши ему лично)
3. Перейди по ссылке: `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`
   - Замени `<BOT_TOKEN>` на токен из шага 1
4. В ответе найди `"chat":{"id":123456789}` - это твой **BOT_CHAT_ID**

### Способ Б: Через @userinfobot

1. Найди бота `@userinfobot`
2. Отправь ему `/start`
3. Бот вернет твой User ID - это **BOT_CHAT_ID** (для личных сообщений)

## 3. Обнови .env.local

Добавь в файл `lead-parser/.env.local`:

```
BOT_TOKEN=123456789:ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefg
BOT_CHAT_ID=123456789
```

## 4. Перезапусти контейнер

```bash
docker restart lead-parser-app
```

## 5. Тестирование

- Откройи веб-интерфейс: http://155.212.208.194:8000/leads/demo/
- Анализируй тестовый лид (например: "Нужен сайт для интернет-магазина, бюджет 150 тыс")
- Если релевантность >= 70%, ты получишь уведомление в Telegram

## Фильтрация

- **По умолчанию** отправляются уведомления только для лидов с релевантностью >= 70%
- Чтобы изменить порог, отредактируй `NOTIFICATION_MIN_RELEVANCE` в `app/notifier.py`

## Дополнительно

- Если используешь **группу** вместо личного чата, добавь бота как администратора
- Убедись что бот имеет права на отправку сообщений
- Используй `/getme` команду BotFather для просмотра информации о боте
