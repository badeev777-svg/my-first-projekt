# 🔍 Скрипт поиска контактов веб-студий

## Что делает?

Автоматически ищет email и телефоны 25 веб-студий:
1. Находит их сайты
2. Парсит страницы контактов
3. Сохраняет результаты в CSV

## Установка

```bash
# 1. Установи зависимости
pip install -r requirements_scraper.txt

# 2. Запусти скрипт
python scrape_contacts.py
```

## Что получишь?

Файл `web_studios_contacts.csv` с колонками:
- **studio** — название студии
- **website** — URL сайта
- **email** — найденный email
- **phone** — найденный телефон

### Пример результата:

```
studio,website,email,phone
ITECH,https://itech-group.ru,hi@itech-group.ru,+7 495 255 03 37
Liqium,https://www.liqium.ru,Info@liqium.ru,+7 495 545 42 35
Digital Lab,https://digital-lab.ru,contact@digital-lab.ru,+7 495 123 45 67
...
```

## Как использовать результаты?

1. **Открой CSV в Excel/Google Sheets** → удали пустые строки
2. **Используй email для рассылки** из шаблона SALES_EMAIL.md
3. **Телефоны опционально** → для холодных звонков

## Что может не сработать?

- ❌ Сайт недоступен → попробуй вручную
- ❌ Email не на сайте → поищи в LinkedIn, Google My Business
- ❌ Динамический сайт → скрипт парсит только статический HTML

## Если не работает?

Самые надёжные варианты для ручного поиска:

```bash
# Google поиск
[название] контакты email

# LinkedIn
site:linkedin.com "[название]"

# Яндекс Карты
Ищи студию → "Подробнее" → контакты
```

---

**Примечание:** Скрипт вежливо ждёт 1 сек между запросами, чтобы не перегружать серверы.
