# Настройка защиты панели администратора

По умолчанию, панель администратора (список лидов) открыта для всех. Чтобы защитить её паролем:

## 1. Установи пароль в .env.local

Добавь в файл `.env.local`:

```
ADMIN_PASSWORD=твой_секретный_пароль
```

Например:

```
ADMIN_PASSWORD=super_secret_password_123
```

## 2. Перезапусти приложение

```bash
docker restart lead-parser-app
```

## 3. Пользуйся админ-панелью

- Перейди на http://155.212.208.194:8000/leads/
- Тебя перенаправит на страницу входа: http://155.212.208.194:8000/leads/login
- Введи пароль
- Будет создана сессия на 7 дней (в куках)

## 4. Выход

Нажми кнопку "Выход" в навигации или перейди на http://155.212.208.194:8000/leads/logout

## Безопасность

⚠️ **Важно:**
- Пароль хранится в виде SHA-256 хеша в памяти приложения
- Сессия хранится в куках с флагом `httponly`
- Используй HTTPS если применяешь на production
- Измени пароль время от времени

## Отключение защиты

Удали `ADMIN_PASSWORD` из `.env.local` и перезапусти приложение.

## Если забыл пароль

1. Отредактируй `.env.local`
2. Установи новый пароль
3. Перезапусти контейнер
