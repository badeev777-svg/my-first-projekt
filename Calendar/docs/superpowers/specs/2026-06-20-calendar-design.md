# Календарь — спецификация

**Дата:** 2026-06-20  
**Платформа:** Android (нативный Kotlin)  
**Аудитория:** Личное использование, один пользователь

---

## Суть приложения

Android-приложение-календарь, в котором можно ставить галочки на задачах прямо с главного экрана, не переходя в отдельный день. Задачи хранятся локально на устройстве. Уведомления — стандартные системные Android.

---

**Паттерн:** MVVM  
**Хранилище:** Room DB (локально, без синхронизации)  
**Уведомления:** WorkManager

## Модель данных

```kotlin
@Entity(tableName = "tasks")
data class Task(
    @PrimaryKey(autoGenerate = true) val id: Int = 0,
    val title: String,
    val date: LocalDate,         // дата задачи
    val time: LocalTime? = null, // время — если указано, будет напоминание за 1 час
    val isDone: Boolean = false
)
```

## Экраны

### Главный экран (MainScreen)

**Верхняя часть — полоса из 7 дней:**
- Навигация по месяцам: стрелки `‹ Июнь 2026 ›`
- 7 ячеек дней (Пн–Вс), свайп влево/вправо = следующая/предыдущая неделя
- Выбранный день — синий фон
- Точка под ячейкой = есть задачи на этот день

**Нижняя часть — список задач выбранного дня:**
- Шапка: «20 июня · 3 задачи»
- Каждый элемент: чекбокс + название + (если есть время) строка с временем и напоминанием
- Тап на чекбокс — переключает `isDone`, зачёркивает название
- Свайп влево по задаче — появляется кнопка «Удалить»
- FAB «+» — переход на экран добавления задачи (дата предзаполнена = выбранный день)

### Экран добавления задачи (AddTaskScreen)

| Поле | Обязательное | Описание |
|------|-------------|----------|
| Название | Да | Текстовый ввод |
| Дата | Да | По умолчанию — выбранный день, редактируется через DatePicker |
| Время | Нет | TimePicker; если указано — показывает подсказку о уведомлениях |

Кнопки: «Отмена» (закрыть без сохранения), «Сохранить» (записать в БД + запланировать уведомления).

## Уведомления

Два типа уведомлений, оба — стандартные Android push:

### 1. Утренний дайджест
- **Когда:** 9:00 в день задачи
- **Текст:** «Сегодня запланировано: [название1], [название2]...»
- **Реализация:** `OneTimeWorkRequest` с начальной задержкой до следующих 9:00, при срабатывании планирует себя на следующий день. WorkManager не гарантирует точное время, поэтому для первого запуска вычисляется `delay = nextDay9am - now`.

### 2. Напоминание перед задачей
- **Когда:** за 1 час до `task.time` (только если время указано)
- **Текст:** «Через час: [название задачи] в [время]»
- **Реализация:** `OneTimeWorkRequest` с задержкой = `task.date + task.time - 1 час - now`, планируется при сохранении задачи

При удалении задачи — соответствующий `WorkRequest` отменяется по тегу `task_reminder_{id}`.

## Что не входит в scope

- Повторяющиеся задачи
- Категории / приоритеты задач
- Синхронизация между устройствами
- Авторизация / аккаунты
- Тёмная/светлая тема (только тёмная)
- Виджет на рабочий стол
