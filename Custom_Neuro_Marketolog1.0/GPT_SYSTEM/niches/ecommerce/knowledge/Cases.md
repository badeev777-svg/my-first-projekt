# Кейсы — E-commerce

## Кейс 1. Магазин женской одежды на Wildberries, Москва
**Проблема:** % возвратов 47% (отраслевая норма 25-30%). Рейтинг карточек падает, позиции теряются. Бюджет на рекламу растёт, выручка — нет.
**Что сделали:**
- Аудит причин возвратов: 68% — «не подошёл размер». Обновили таблицы размеров + добавили фото на модели разных комплекций
- Внедрили автоматический сбор отзывов: через 10 дней после доставки — сообщение в WB-чат с просьбой об отзыве
- Подключили аналитику WB через mpstats: выявили 5 «аутсайдеров» по маржинальности — вывели из ассортимента
- Перераспределили рекламный бюджет с «широкого таргета» на буст топовых карточек с рейтингом 4.7+
**Результат за 2 месяца:**
- % возвратов: 47% → 29%
- Средний рейтинг карточек: 4.2 → 4.6
- Выручка +34% при том же рекламном бюджете

## Кейс 2. Интернет-магазин электроники, собственный сайт + Ozon, Казань
**Проблема:** 87% продаж — через Ozon (комиссия 18-22%). Сайт есть, но конверсия 0.4%. Своей базы клиентов нет.
**Что сделали:**
- В каждую посылку вложили вкладыш: «Следующий заказ на сайте — минус 7%». QR-код на страницу регистрации
- Запустили email-рассылку по собранной базе: раз в 2 недели — «Подборка недели», скидки постоянным покупателям
- CRO-аудит сайта: упростили корзину (убрали 3 лишних шага), добавили онлайн-чат, ускорили загрузку мобильной версии
- Триггерные письма: брошенная корзина → письмо через 1 час → второе через 24 часа со скидкой 3%
**Результат за 3 месяца:**
- Конверсия сайта: 0.4% → 1.3%
- Доля заказов через собственный сайт: 13% → 31%
- Экономия на комиссиях: ~140 000 ₽/мес.

## Кейс 3. Детские товары на Ozon + Instagram, Новосибирск
**Проблема:** CAC через таргет Instagram — 1 800 ₽. Средний чек 900 ₽. Единственная покупка — убыток. Нет повторных продаж.
**Что сделали:**
- Запустили Telegram-канал «для мам»: контент про развитие детей + анонсы новинок. 4 поста в неделю
- Воронка: Instagram → подписка на Telegram → welcome-скидка 10% → первая покупка
- После первой покупки — автоматическое сообщение в Telegram на 21-й день: рекомендация следующего товара по возрасту ребёнка
- Реферральная программа: «Порекомендуй подруге — оба получите скидку 15%»
**Результат за 4 месяца:**
- % повторных покупателей: 11% → 38%
- CAC эффективный (с учётом LTV): снизился с 1 800 ₽ до 620 ₽
- Telegram-канал: 4 800 подписчиков, 22% конверсия подписчик → покупка за 6 месяцев

## Кейс 4. Магазин натуральной косметики D2C, только сайт, Санкт-Петербург
**Проблема:** Высокий первый чек (2 200 ₽), но 78% покупают один раз. Email есть, открываемость 6%. LTV = средний чек × 1.
**Что сделали:**
- Сегментировали базу по категории первой покупки: уход за лицом / тело / волосы
- Запустили персонализированные цепочки: 3 письма после покупки по теме сегмента с рекомендациями дополняющих товаров
- Добавили «подписку» на популярные товары (крем, сыворотка) с скидкой 12% и автодоставкой
- Через 45 дней после покупки — «пора пополнить?» с кнопкой в один клик
**Результат за 5 месяцев:**
- % повторных покупок: 22% → 51%
- Открываемость писем: 6% → 31% (за счёт персонализации)
- Подписка на автодоставку: 14% покупателей (постоянная выручка)
- LTV вырос в 2.8 раза
