# Как использовать нишевые шаблоны

## Структура

```
niches/
  beauty/            — салоны красоты, косметология, SPA
  restaurants/       — рестораны, кафе, доставка еды
  online_education/  — курсы, онлайн-школы, коучинг
  legal/             — юридические фирмы, частные практики
  b2b_sales/         — B2B-продажи: производство, дистрибуция, услуги юрлицам
  ecommerce/         — интернет-магазины, маркетплейсы, D2C
  construction/      — строительство, ремонт, отделка
  medical/           — стоматология, частные клиники, косметология
```

Каждая ниша содержит:
- `Instructions.txt` — адаптированный промпт агента
- `knowledge/Cases.md` — 4 реальных кейса по нише

## Как настроить проект под нишу клиента

### Шаг 1. Замените инструкции агента
```bash
cp niches/beauty/Instructions.txt GPT_1_NeuroMarketing/Instructions.txt
```

### Шаг 2. Добавьте нишевые кейсы в knowledge base
```bash
cp niches/beauty/knowledge/Cases.md knowledge/cases/Cases_Beauty.md
```

### Шаг 3. Обновите .env под клиента
```env
AGENT_NAME=AI-Консультант по салонному бизнесу
AGENT_INITIALS=AI
AGENCY_NAME=Название агентства клиента
CONTACT_LINK=https://t.me/клиент
CHAT_ONLY_MODE=true
```

### Шаг 4. Запустите деплой
```bash
bash deploy.sh
```

## Доработка под конкретного клиента

После замены базового шаблона можно дополнить:
- `GPT_1_NeuroMarketing/Instructions.txt` — добавить специфику конкретной компании,
  уникальные продукты, географию, целевую аудиторию
- `knowledge/` — загрузить реальные кейсы клиента, его прайс, описание услуг

## Какую нишу использовать

| Клиент | Ниша |
|--------|------|
| Салон красоты, барбершоп, студия маникюра | beauty |
| Кафе, ресторан, кофейня, доставка еды | restaurants |
| Онлайн-курсы, школы, коучи, эксперты | online_education |
| Юридическая фирма, адвокат, нотариус | legal |
| Производитель, дистрибьютор, B2B-услуги, опт | b2b_sales |
| Интернет-магазин, Wildberries/Ozon, D2C | ecommerce |
| Ремонт квартир, строительство, отделка | construction |
| Стоматология, частная клиника, косметология | medical |
| Универсальный / другая ниша | базовый GPT_1_NeuroMarketing/Instructions.txt |
