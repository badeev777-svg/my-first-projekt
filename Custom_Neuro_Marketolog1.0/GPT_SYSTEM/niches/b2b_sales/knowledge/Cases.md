# Кейсы — B2B-продажи

## Кейс 1. Производитель корпусной мебели, 15 менеджеров, Екатеринбург
**Проблема:** Конверсия лид → договор 8%. Менеджеры теряют лиды: «забыли перезвонить», «не дозвонились». CRM есть (amoCRM), но используется как записная книжка.
**Что сделали:**
- Настроили обязательную воронку в amoCRM: каждый лид — статус, дата следующего касания, задача
- Автоматические напоминания менеджеру, если лид «завис» без движения более 2 дней
- Еженедельный отчёт РОПу: pipeline по стадиям, просроченные задачи, конверсии
- Скрипт первого касания + шаблоны КП для 3 сегментов (розница, сети, B2B-корпоратив)
**Результат:**
- Конверсия лид → договор: 8% → 19%
- Средний цикл сделки: 34 дня → 21 день
- Выручка выросла на 31% без увеличения рекламного бюджета

## Кейс 2. IT-аутсорсинговая компания, 3 менеджера, Москва
**Проблема:** Весь лидген — сарафан. Новых клиентов 2-3 в месяц. Собственник лично закрывает 80% сделок, уперлись в потолок.
**Что сделали:**
- Запустили LinkedIn outreach: персональные сообщения ЛПР в IT и финансовом секторе
- Кейсы оформили в одностраничные PDF: конкретная задача → решение → результат в цифрах
- Настроили квалификационный бот в Telegram: входящий лид проходит 5 вопросов → «горячий» лид передаётся менеджеру с резюме
- Прописали регламент передачи сделки от менеджера к техническому эксперту
**Результат:**
- Новых лидов в месяц: с 3 до 18 (квалифицированных — 8-10)
- Доля закрытых сделок без участия собственника: с 20% до 65%
- Средний чек вырос на 22% (менеджеры начали продавать по стандарту, а не «по-своему»)

## Кейс 3. Дистрибьютор строительных материалов, 8 менеджеров, Нижний Новгород
**Проблема:** 60% выручки — 3 клиента. Риски концентрации. Новые клиенты не приживаются: делают 1-2 заказа и уходят.
**Что сделали:**
- Сегментировали базу клиентов: A (ключевые), B (потенциал роста), C (разовые)
- Для сегмента B: ежемесячная автоматическая рассылка с персональными условиями + новинками
- Программа welcome-онбординга для новых клиентов: звонок от менеджера на 3-й и 14-й день
- Автоматическое уведомление менеджеру, если клиент не сделал заказ 45+ дней (реактивация)
**Результат:**
- Доля топ-3 клиентов в выручке: с 60% до 38%
- Retention клиентов после 3-го месяца: с 31% до 54%
- +12 новых регулярных клиентов за квартал без роста команды

## Кейс 4. SaaS-продукт для ритейла, 5 продажников, Санкт-Петербург
**Проблема:** Высокий churn: 24% клиентов отменяют подписку в первые 3 месяца. Продают, но не удерживают.
**Что сделали:**
- Onboarding-бот после подключения: задаёт вопросы, выдаёт персональный чек-лист настройки
- Автоматическое письмо на 7-й, 14-й, 30-й день: «Вы уже сделали X — вот следующий шаг»
- Система «health score»: менеджер видит клиентов с низкой активностью → проактивный звонок
- NPS-опрос на 45-й день: при оценке ≤6 — немедленный звонок от CSM
**Результат:**
- Churn в первые 3 месяца: 24% → 9%
- LTV клиента вырос в 2.4 раза
- NPS: 31 → 58
