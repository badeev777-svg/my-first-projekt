## Кейс №1 — AI Lead Parser: система автоматического поиска лидов

**Задача:** Разработчик-фрилансер тратил 2–3 часа в день на ручной мониторинг FL.ru, Kwork и других площадок в поисках подходящих заказов. Большинство задач находили уже с 5–10 откликами — поздно.

**Решение:** AI-система мониторинга заказов с автоматической квалификацией.

**Стек:** Python + FastAPI + Playwright + Claude API (OpenRouter) + PostgreSQL + Telegram Bot + Beget VPS

**Что сделано:**
- 5 источников: FL.ru, Kwork.ru, Profi.ru, freelance.ru, VK-группы — опрос каждые 10 минут
- AI-анализ каждого лида: релевантность (0–100%), теги, краткое резюме, оценка бюджета
- Telegram-уведомления только для лидов с релевантностью ≥ 70%
- Веб-дашборд: KPI-карточки, графики по источникам и времени, таблица платформ, CSV-экспорт
- UI настройки фильтров (ключевые слова, стек, бюджет) без перезапуска

**Результат:**
- ~68 лидов в цикл сбора (10 минут) из 5 площадок
- Время на мониторинг: 2–3 часа/день → 0 (полностью автоматически)
- Реакция на новый заказ: первые минуты после публикации
- Система развёрнута в production на VPS (155.212.208.194)

**Технический стек для клиента:** Аналогичная система для B2B-компании — мониторинг тендеров, парсинг объявлений о закупках, квалификация заявок по профилю компании.

**Стоимость разработки:** 80–150K ₽ | MVP за 2–3 недели

## Кейс №2 — AI-менеджер продаж «Алекс»

**Задача:** Агентство не успевало обрабатывать входящие обращения — потенциальные клиенты писали вечером или в выходные и уходили без ответа. Нужен был первичный контакт 24/7.

**Решение:** AI-агент «Алекс» — менеджер по продажам в Telegram и на сайте.

**Стек:** FastAPI + aiogram 3.x + OpenRouter (Claude) + SQLite + Telegram Bot API

**Что умеет агент:**
- Ведёт диалог о продуктах агентства, отвечает на вопросы, снимает возражения
- Детектирует готовность клиента к сделке через специальный тег в ответе
- Сохраняет лид в CRM: имя, контакт, задача, интерес к продукту
- Мгновенно уведомляет Александра в Telegram с inline-кнопкой «Написать клиенту» (прямая ссылка на диалог)
- Веб-CRM: список лидов со сменой статусов (Новый / В работе / Закрыт)

**Продукты агентства в базе знаний агента:**
- Lead Parser: 30–80K ₽
- Telegram-бот с AI: 50–150K ₽
- AI-агент под бизнес: 50–200K ₽
- Автоматизация процессов: 30–120K ₽

**Результат (ожидаемый после деплоя):**
- Первый ответ клиенту: ≤ 30 секунд (сейчас — среднее 2–4 часа)
- Квалифицированные лиды приходят готовыми к разговору, а не с нуля
- Менеджер тратит время только на горячих лидов

**Стоимость разработки:** 50–120K ₽ | MVP за 2 недели

## Кейс №3 — Content Agent Bot: мультиагентная система SMM-контента

**Задача:** SMM-агентство тратило 70% времени команды на производство контента для 10+ клиентов. Каждый пост — согласование брифа, написание, правки. Масштабироваться было невозможно.

**Решение:** Мультиагентный Telegram-бот для автоматизации контент-производства.

**Стек:** Python + aiogram + OpenRouter (Claude Sonnet) + SQLAlchemy + Docker

**Архитектура — 3 агента в конвейере:**
1. **Scraper** — собирает тезисы из URL или темы
2. **Strategist** — строит 7-дневную контент-воронку (вовлечение → экспертность → доверие → продажа)
3. **Copywriter** — адаптирует контент под 4 платформы: Telegram, VK, Stories, VC.ru

**Функционал:**
- Онбординг: 5 вопросов для создания профиля бренда и tone-of-voice
- Кнопки редактирования: «Переписать», «Короче», «Формальнее»
- Лимит 3 переработки/день на тариф 2 499 ₽/мес (защита от токен-перерасхода)
- 70/70 тестов — полное покрытие модулей

**Результат:**
- x3 скорость производства контента
- Себестоимость поста: минуты вместо часов
- Единый стиль бренда на всех платформах автоматически

**Стоимость разработки:** 80–150K ₽ кастом | SaaS 2 499 ₽/мес

## Кейс №4 — SpeakBuddy: AI-тьютор разговорного английского

**Задача:** Образовательный стартап хотел запустить сервис для практики разговорного английского без живого репетитора. Живые уроки — 1 500–3 000 ₽/час, недоступно для массовой аудитории.

**Решение:** Telegram-бот с AI на базе Claude — неограниченная практика диалогов.

**Стек:** Python + python-telegram-bot + Claude API + PostgreSQL + Redis + ЮKassa + Telegram Stars

**Функционал (Phase 1–2 реализованы):**
- Онбординг: 7 вопросов для определения уровня (A1–C2)
- 6 сценариев диалогов: кафе, аэропорт, деловая встреча, собеседование, покупки, путешествие
- Разбор ошибок и грамматические подсказки (премиум)
- Freemium: 10 сообщений/день бесплатно
- Монетизация: 299 ₽/мес или 2 499 ₽/год
- Платежи: Telegram Stars (встроено в экосистему) + ЮKassa для карт

**Целевая аудитория:** 20–45 лет, студенты и работающие из РФ и СНГ

**Модель юнит-экономики:**
- Себестоимость 1 пользователя/мес: ~30–50 ₽ (Claude API tokens)
- Маржинальность: 85%+ при 500+ активных пользователях
- CAC через Telegram: 200–500 ₽

**Стоимость разработки:** 100–200K ₽ | MVP за 4–6 недель
