# CRM-АВТОМАТИЗАЦИЯ — Шаблоны и паттерны

## Типовые сценарии автоматизации CRM

### 1. Автоквалификация лидов
Триггер: новый лид в CRM
Действие: AI анализирует данные лида, присваивает скоринг, ставит тег
Результат: менеджер получает только квалифицированные лиды

### 2. Авторассылка по воронке
Триггер: переход лида на следующий этап
Действие: отправка письма / сообщения в Telegram
Результат: лид получает нужный контент в нужный момент

### 3. Автонапоминания менеджерам
Триггер: лид завис на этапе более N дней
Действие: уведомление менеджеру в Telegram
Результат: ни один лид не теряется

### 4. Автозаполнение карточки клиента
Триггер: входящее сообщение / звонок
Действие: AI извлекает ключевые данные, записывает в CRM
Результат: менеджер не тратит время на ручной ввод

### 5. Автоотчёты по продажам
Триггер: расписание (ежедневно / еженедельно)
Действие: AI формирует отчёт из данных CRM
Результат: руководитель получает сводку без запроса

## Интеграционная схема

Telegram/WhatsApp → Webhook → Backend → LLM → CRM API
                                      ↓
                              Уведомление менеджеру
