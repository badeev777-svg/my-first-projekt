# ПРИМЕРЫ АРХИТЕКТУР AI-РЕШЕНИЙ

## Пример 1. AI-квалификатор лидов (Telegram)

Пользователь пишет в бот
      ↓
Бот задаёт 3–5 квалификационных вопроса
      ↓
LLM анализирует ответы → присваивает скоринг
      ↓
Если скоринг > порога → запись на звонок → CRM
Если скоринг < порога → nurturing-сценарий

Стек: aiogram + Claude API + PostgreSQL + AmoCRM webhook
Срок MVP: 2–3 недели

---

## Пример 2. AI-консультант на сайте

Пользователь открывает чат на сайте
      ↓
AI отвечает на вопросы из базы знаний (RAG)
      ↓
Если вопрос вне базы → передача оператору
      ↓
Если интерес к покупке → предлагает оставить заявку → CRM

Стек: FastAPI + Claude API + Pinecone (RAG) + виджет на сайт
Срок MVP: 3–4 недели

## Пример 3. Мультиагентная система продаж

Входящий лид (форма / Telegram / email)
      ↓
Агент-квалификатор → скоринг + теги
      ↓
Агент-нутринг → персонализированные сообщения
      ↓
Агент-менеджер → запись на звонок + передача человеку
      ↓
Агент-аналитик → еженедельный отчёт по воронке

Стек: n8n (оркестратор) + Claude API + CRM + Telegram
Срок: 6–8 недель

## Пример 4. AI-поддержка клиентов

Клиент пишет в Telegram/WhatsApp
      ↓
Классификация запроса (LLM)
      ├── FAQ → автоответ из базы знаний
      ├── Технический вопрос → поиск в документации
      └── Сложный кейс → передача оператору + сводка контекста

Стек: aiogram + Claude API + база знаний (Notion/Google Docs) + уведомления
Срок MVP: 2 недели
