## Что входит в каждый тариф

### MVP (2–3 недели)
- 1–2 ключевых сценария (например: приём заявки + квалификация)
- Интеграция с одним каналом (Telegram или сайт)
- Базовая аналитика (логи, уведомления)
- Поддержка: 1 месяц — исправление багов
- Деплой на VPS включён

**Подходит:** протестировать гипотезу, показать результат инвестору, запустить первую версию

---

### Стандарт (4–6 недель)
- Полный функционал под задачу
- Интеграция: CRM (AmoCRM / Bitrix24 / Notion) + мессенджер (Telegram / WhatsApp)
- Веб-панель управления (просмотр лидов, статусы, фильтры)
- Аналитический дашборд (графики, KPI, CSV-выгрузка)
- Поддержка: 3 месяца
- Деплой + CI/CD настройка

**Подходит:** рабочий инструмент для команды, замена ручного процесса

---

### Под ключ (по проекту, от 8 недель)
- Кастомная архитектура под специфику бизнеса
- Все нужные интеграции (CRM + мессенджеры + email + внешние API)
- Обучение команды (2–4 часа онлайн-сессии)
- Документация: пользовательская + техническая
- Поддержка: 6 месяцев
- SLA по времени ответа на инциденты

**Подходит:** системное внедрение, несколько отделов, интеграция с корпоративной инфраструктурой

## Модели оплаты

**Фиксированная стоимость проекта** — рекомендуется для MVP и Стандарт.
Оплата поэтапно: 50% предоплата → 50% после сдачи.

**Помесячная подписка** — для SaaS-продуктов (Content Agent Bot — 2 499 ₽/мес).
Включает хостинг, обновления, базовую поддержку.

**Поддержка + развитие** — ежемесячный ретейнер после сдачи проекта.
10–30K ₽/мес в зависимости от объёма задач.
