# АНАЛИЗ КОНКУРЕНТОВ — Шаблон и методология

## Что анализировать

### 1. УТП и позиционирование
- Как конкурент себя позиционирует?
- Что является его главным отличием?
- На какой сегмент ориентируется?

### 2. Продуктовая линейка
- Какие услуги/продукты предлагает?
- Есть ли пакеты / тарифы?
- Что входит в базовый оффер?

### 3. Ценообразование
- Ценовой диапазон
- Модель монетизации (разово / подписка / % от результата)
- Наличие бесплатного входа (freemium, лид-магнит)

### 4. Каналы трафика
- Сайт (SEO, контент)
- Telegram-канал
- Соцсети (ВК, Instagram, YouTube)
- Реклама (таргет, контекст)
- Партнёрства

### 5. Контент и маркетинг
- Темы контента
- Форматы (посты, видео, кейсы)
- Частота публикаций
- Вовлечённость аудитории

### 6. Воронка продаж
- Лид-магнит (что предлагают бесплатно?)
- Точка входа (сайт / бот / звонок)
- Механика продажи

## Возможности для отстройки
После анализа определи:
1. Что конкуренты делают плохо?
2. Какие сегменты они игнорируют?
3. Какое позиционирование свободно?
4. Где можно предложить больше ценности за ту же цену?
