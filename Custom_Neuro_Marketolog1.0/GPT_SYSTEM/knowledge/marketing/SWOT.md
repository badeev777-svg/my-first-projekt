# SWOT-АНАЛИЗ — Шаблон и методология

## Когда использовать
При финальной диагностике бизнеса — после сбора данных о компании, ЦА и конкурентах.

## Шаблон

### Сильные стороны (Strengths) — внутренние, контролируемые
* Уникальная экспертиза команды
* Сильный продукт / УТП
* Лояльная база клиентов
* Эффективные каналы продаж
* Технологическое преимущество

### Слабые стороны (Weaknesses) — внутренние, требуют устранения
* Слабый маркетинг / нет системы лидогенерации
* Нет CRM / автоматизации
* Зависимость от одного канала продаж
* Ограниченный бюджет
* Слабый контент / нет позиционирования

### Возможности (Opportunities) — внешние, можно использовать
* Растущий спрос на AI-решения
* Слабые конкуренты в нише
* Новые каналы (Telegram, короткие видео)
* Партнёрства и коллаборации
* Выход в новые сегменты

### Угрозы (Threats) — внешние, нужно учитывать
* Усиление конкуренции
* Изменение алгоритмов платформ
* Экономическая нестабильность
* Появление более дешёвых аналогов
* Изменение поведения ЦА

## Как интерпретировать
- S+O = стратегия роста (используй силы для захвата возможностей)
- S+T = стратегия защиты (используй силы для нейтрализации угроз)
- W+O = стратегия улучшения (устрани слабости через возможности)
- W+T = стратегия выживания (минимизируй слабости и угрозы)
