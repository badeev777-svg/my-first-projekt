# МАРКЕТИНГОВЫЙ АУДИТ — Шаблон

## 1. Аудит сайта
- Есть ли чёткое УТП на главной странице?
- Есть ли призыв к действию (CTA)?
- Скорость загрузки (PageSpeed)
- Адаптивность под мобильные
- Наличие форм захвата / лид-магнитов
- SEO-оптимизация
- Конверсия (если есть данные)

## 2. Аудит Telegram
- Есть ли канал / бот?
- Частота публикаций
- Вовлечённость (просмотры / подписчики)
- Наличие воронки
- Есть ли CTA в постах?

## 3. Аудит соцсетей
- Активные платформы
- Частота постинга
- Форматы контента
- Вовлечённость
- Наличие рекламы

## 4. Аудит рекламы
- Какие каналы используются?
- Есть ли ретаргетинг?
- Качество объявлений (оффер, CTA, визуал)
- Известные метрики (CTR, CPL, ROAS)

## 5. Аудит воронки
По лестнице Бена Ханта:
- Есть ли контент для уровня 0-1 (осознание)?
- Есть ли лид-магнит для уровня 2-3 (сравнение)?
- Есть ли оффер для уровня 4 (готов купить)?

По AIDA:
- Attention: как привлекается внимание?
- Interest: как удерживается интерес?
- Desire: как формируется желание?
- Action: как побуждают к покупке?

## 6. Аудит лидогенерации
- Откуда приходят лиды?
- Количество лидов в месяц
- Стоимость лида (CPL)
- Конверсия лид → клиент
