# AI-АГЕНТЫ — Архитектурные паттерны

## Типы агентов

### 1. Реактивный агент (простой бот)
Получает запрос → даёт ответ из базы знаний.
Применение: FAQ, поддержка, консультации.
Стек: LLM + база знаний (RAG или static).

### 2. Агент с памятью
Помнит контекст разговора, историю клиента.
Применение: продажи, онбординг, обучение.
Стек: LLM + БД (PostgreSQL/SQLite) + история диалогов.

### 3. Агент с инструментами (Tool-use)
Может вызывать внешние API: CRM, календарь, поиск.
Применение: менеджер продаж, аналитик, рекрутер.
Стек: LLM + Function calling + интеграции.

### 4. Мультиагентная система
Несколько агентов работают как команда, передают данные друг другу.
Применение: сложные бизнес-процессы, конвейеры.
Стек: LLM + оркестратор (n8n/custom) + специализированные агенты.

## Архитектурный шаблон одного агента

Вход (триггер):
- Telegram-сообщение
- Форма на сайте
- Email
- Вебхук CRM

Обработка:
1. Классификация запроса
2. Извлечение контекста (память / база знаний)
3. Генерация ответа (LLM)
4. Вызов инструментов (если нужно)
5. Форматирование ответа

Выход:
- Ответ пользователю
- Запись в CRM
- Уведомление менеджеру
- Следующий шаг воронки
