# КАТАЛОГ AI-РЕШЕНИЙ

## AI-Менеджер продаж
Задачи: обработка лидов, квалификация, запись на звонок.
Для кого: агентства, эксперты, SaaS, онлайн-школы.
Стек: LLM + Telegram/WhatsApp + CRM.
MVP: бот квалификации → передача в CRM → уведомление менеджеру.
Эффект: рост конверсии, ускорение обработки заявок.

## AI-Консультант Telegram
Задачи: ответы на вопросы, продажа услуг, сбор заявок.
Стек: LLM + Telegram Bot API + база знаний.
MVP: бот с FAQ + форма заявки + уведомление.
Эффект: продажи 24/7 без менеджера.

## AI-Оператор поддержки
Задачи: FAQ, поддержка клиентов, маршрутизация сложных запросов.
Стек: LLM + база знаний + эскалация на оператора.
MVP: автоответы на топ-20 вопросов + передача сложных кейсов.
Эффект: -60% нагрузки на поддержку.

## AI-Аналитик
Задачи: анализ данных, подготовка отчётов, рекомендации.
Стек: LLM + Google Sheets/Notion + дашборд.
MVP: автоматический недельный отчёт по ключевым метрикам.
Эффект: решения на основе данных, экономия времени на аналитику.

## AI-Маркетолог
Задачи: анализ конкурентов, анализ ЦА, генерация контента, создание офферов.
Стек: LLM + парсеры + контент-пайплайн.
MVP: еженедельный контент-план + 5 постов.
Эффект: x3 скорость контента, -40% расходов.

## AI-Рекрутер
Задачи: обработка резюме, первичный скрининг, оценка кандидатов.
Стек: LLM + форма + автоответы + скоринг.
MVP: автоматический скрининг входящих резюме.
Эффект: ускорение найма в 2 раза.

## AI-Проектный менеджер
Задачи: контроль задач, контроль сроков, отчётность.
Стек: LLM + Notion/Trello + уведомления Telegram.
MVP: автоматические статус-апдейты по проектам.
Эффект: прозрачность проектов, меньше ручного контроля.
