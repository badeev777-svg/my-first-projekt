Для предпринимательских Telegram-чатов, бизнес-форумов, комментариев в соцсетях.

## Правила для чатов

1. **Только если релевантно** — не спамь вне темы
2. **Не более 1 раза в чат в неделю**
3. **Добавляй UTM** к ссылке: `?utm_source=tg_chat&utm_medium=organic`
4. **Отвечай на возражения** — если спросят "а это реклама?": "Нет, просто инструмент который сделал, делюсь"
5. **Не дублируй** одинаковый текст — меняй формулировки между чатами
