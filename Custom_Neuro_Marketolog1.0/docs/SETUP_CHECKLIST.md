# Чеклист установки — AI-Маркетолог (White-label)

Документ для Badeev Agency. Используется при каждом новом клиенте.
Заполняется сверху вниз. Время выполнения: ~2–4 часа.

## 1. Подготовка пакета

- [ ] Определена ниша клиента
- [ ] Скопированы инструкции нужной ниши:
  ```bash
  cp GPT_SYSTEM/niches/{НИША}/Instructions.txt GPT_SYSTEM/GPT_1_NeuroMarketing/Instructions.txt
  ```
- [ ] Скопированы нишевые кейсы:
  ```bash
  cp GPT_SYSTEM/niches/{НИША}/knowledge/Cases.md GPT_SYSTEM/knowledge/cases/Cases_{КЛИЕНТ}.md
  ```
- [ ] (Опционально) Добавлены реальные кейсы клиента в `knowledge/cases/`
- [ ] Создан архив:
  ```bash
  bash package.sh {имя_клиента}
  ```
- [ ] Архив проверен: `tar -tzf neuro-marketolog-*.tar.gz | head -20`

---

## 2. Доступ к VPS

- [ ] SSH подключение работает:
  ```bash
  ssh root@{IP}
  ```
- [ ] Ubuntu 22.04 или 24.04:
  ```bash
  lsb_release -a
  ```
- [ ] Свободно минимум 1 GB RAM и 5 GB диска:
  ```bash
  free -h && df -h /
  ```
- [ ] Порт 80 и 443 открыты (или будут открыты Nginx)
- [ ] Домен/субдомен уже указывает на IP VPS:
  ```bash
  nslookup {домен}
  ```

---

## 3. Деплой

- [ ] Архив загружен на VPS:
  ```bash
  scp neuro-marketolog-*.tar.gz root@{IP}:/tmp/
  ```
- [ ] Архив распакован:
  ```bash
  cd /tmp && tar xzf neuro-marketolog-*.tar.gz
  ```
- [ ] Запущен deploy.sh (интерактивно вводим параметры):
  ```bash
  bash deploy.sh
  ```
  Во время скрипта вводим:
  - Домен клиента
  - Email для SSL
  - cloud.ru API key
  - Параметры брендинга (имя агента, компания, CTA-ссылка)
  - CHAT_ONLY_MODE: true (для white-label без лендинга)
  - TG_BOT_TOKEN и TG_CHAT_ID (если нужны уведомления)

- [ ] Скрипт завершился без ошибок
- [ ] Сервис запущен:
  ```bash
  systemctl status neuro-marketolog
  # ожидаем: active (running)
  ```

---

## 4. Проверка после деплоя

### 4.1 Базовая проверка

- [ ] Сайт открывается по домену: `https://{домен}`
- [ ] SSL-сертификат выдан (замочек в браузере, не самоподписанный)
- [ ] Чат отображает правильное имя агента
- [ ] Аватар агента показывает правильные инициалы
- [ ] Кнопка «Начать» работает

### 4.2 Проверка диагностики

- [ ] Агент представляется и задаёт первый вопрос нужной ниши
- [ ] Вопросы соответствуют нише (проверить 3-4 хода диалога)
- [ ] Агент не использует шаблонные ответы «не по теме»
- [ ] Handoff-блок появляется после прохождения всех 5 блоков
- [ ] После handoff появляется CTA-кнопка со ссылкой клиента

### 4.3 Уведомления (если настроены)

- [ ] Пройти диагностику до конца
- [ ] Уведомление пришло в Telegram клиента
- [ ] В уведомлении есть резюме разговора

### 4.4 Мобильная версия

- [ ] Открыть на смартфоне: чат читаем, кнопки не обрезаны
- [ ] Клавиатура не перекрывает поле ввода

### 4.5 Нагрузочный тест (быстрый)

- [ ] Открыть 3 вкладки одновременно → каждая работает независимо
- [ ] Сессии не перемешиваются

## 5. Финальные настройки

- [ ] Логи чистые (нет ERROR/WARNING при нормальной работе):
  ```bash
  journalctl -u neuro-marketolog -n 30 --no-pager
  ```
- [ ] Автозапуск включён (после перезагрузки сервера):
  ```bash
  systemctl is-enabled neuro-marketolog
  # ожидаем: enabled
  ```
- [ ] (Опционально) Настроен rate-limiting в Nginx (проверить nginx.conf)
- [ ] .env защищён:
  ```bash
  ls -la /opt/neuro-marketolog/web/.env
  # ожидаем: -rw------- (600)
  ```

## Типичные проблемы и решения

| Проблема | Решение |
|---------|---------|
| `502 Bad Gateway` | `systemctl restart neuro-marketolog` |
| SSL не выдаётся | Домен ещё не propagated — подождать до 1 часа, затем `certbot --nginx -d {домен}` |
| Агент отвечает на английском | Проверить `Instructions.txt` — убедиться что файл нужной ниши скопирован |
| Нет уведомлений в Telegram | Проверить `TG_BOT_TOKEN` и `TG_CHAT_ID` в `.env`, перезапустить сервис |
| `429 Too Many Requests` | Лимит cloud.ru — пополнить баланс в личном кабинете cloud.ru |
| Кейсы не используются в диалоге | Перезапустить сервис после добавления файлов в `knowledge/` |
