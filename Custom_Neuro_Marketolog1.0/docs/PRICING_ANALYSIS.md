## Оценка #2 — Цена для клиента (продажная)

**Текущая цена: 50–80 000₽** (указана в `docs/offer.html`)

Для сравнения с рынком:
- Кастомный чатбот от агентства: **150–300к₽** + ежемесячная поддержка
- Готовые платформы (Manychat, Salebot): **3–15к₽/мес** + ограничения, данные не на своём сервере
- Квалификатор лидов от крупного агентства: **200–400к₽**

**Почему 50-80к — выгодно для клиента:**
- Код на его сервере — нет зависимости от нас как SaaS
- Безлимит по пользователям — платит только за OpenRouter (~$20-50/мес)
- Настроено под его нишу с реальными кейсами
- Установлено за 2-4 часа, не 2 недели

---

## Оценка #3 — Ценность как бизнес (white-label)

```
10 клиентов/мес × 65 000₽ = 650 000₽ выручки
Затраты: ~10% (хостинг клиентов не наш, API не наш)
Маржа: ~580 000₽/мес

Время на 1 установку: 2-4 часа (по SETUP_CHECKLIST.md)
```

**Что делает продукт сильным:**
1. **Handoff механизм** — не просто чатбот, а квалификатор лидов с передачей резюме клиенту
2. **8 ниш** — можно идти в разные рынки параллельно без переработки кода
3. **deploy.sh** — установка за 2 часа, не недели разработки
4. **rglob knowledge base** — клиент может сам добавлять кейсы, никаких обращений к нам

## Стратегия выхода на рынок

**Главное слабое место сейчас:** нет живых примеров по нишам.

**Рекомендуемый путь:**
1. Первые 3-5 клиентов — по себестоимости (20-30к₽) или бесплатно за отзыв + кейс с метриками
2. После 3 кейсов с результатами — поднять цену до 80к₽
3. После 5 кейсов — поднять до 100-120к₽ и продавать уверенно

**Ниши с наибольшим платёжеспособным спросом (в приоритете):**
- B2B-продажи (компании с бюджетом на маркетинг)
- Медицина/стоматология (высокий средний чек, мотивация к лидам)
- Строительство (конкуренция высокая, нужна квалификация)
