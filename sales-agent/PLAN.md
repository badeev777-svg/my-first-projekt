## 2026-10-15 — фиксы приёмки и смена модели

- Модель `ai-sage/GigaChat3.5-432B-A28B` пропала из списка cloud.ru (пока ещё отвечает). Пробовали `GigaChat3.5-…-Reasoning`: вызов навыка 18–20+ с, ответ клиенту ~43 с, таймауты → 503. Выбрана **`GigaChat/GigaChat-2-Max`**: вся приёмка ~50 с. Стоимость на ход для продажника не замерена (в rag-demo ~0,47 ₽ за один вызов — не проверено для этого конвейера).
- Модель сама просила телефон → `contact_request` отклонял обе попытки → заглушка (№1). Теперь код вырезает предложения с просьбой контакта (`strip_contact_asks`), просьбу и текст согласия показывает только код.
- «Скидки по согласованию / уточнит менеджер» считались обещанием скидки (№6) → признаются честным ответом.
- Цена словами «рублей» вместо «₽» больше не дублируется кодом (`mentions_price`).
- Живой скрипт №1: если контакт пришёл до согласия, клиент присылает его повторно.
- Замечания к текстам (не блокируют): бот говорит «менеджер» вместо «Александр»; в №5 после отказа предлагает лендинг.
