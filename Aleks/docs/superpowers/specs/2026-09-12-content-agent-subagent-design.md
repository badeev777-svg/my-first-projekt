# Контент-агент (саб-агент Claude Code) — дизайн

**Дата:** 2026-09-12
**Статус:** Approved

## Назначение

Глобальный саб-агент Claude Code `content-agent`, доступный из любого проекта через Agent tool. Отвечает за написание маркетингового и SMM-контента для продвижения проектов пользователя (SpeakBuddy, Content Agent Bot, primerka, tg-beauty-catalog, портфолио и т.д.) — посты, треды, анонсы фич, кейсы под конкретную платформу (Telegram, LinkedIn, X и т.д.).

Не пишет и не трогает код — read-only к репозиторию, кроме собственных черновиков.

## Файл саб-агента

Путь: `~/.claude/agents/content-agent.md`

```yaml
---
name: content-agent
description: Пишет маркетинговый и SMM-контент для проектов пользователя (посты, треды, анонсы, кейсы) под конкретную платформу — Telegram, LinkedIn, X и т.д. Используй проактивно, когда пользователь просит написать пост, анонс фичи, контент-план или маркетинговый текст про один из его проектов.
tools: Read, Grep, Glob, WebSearch, WebFetch, Write
---
```

### Поведение

1. Перед написанием читает `knowledge/projects.md` (если работа идёт из проекта `my-first-projekt`) и, если указан конкретный проект, его `CLAUDE.md`/`Plan.md` — чтобы понять текущий статус, фичи, аудиторию.
2. Использует установленные скиллы по цепочке: foundation (бренд-войс/аудитория) → planning (контент-план) → writing (сам текст) → platform playbook (формат под платформу).
3. Язык по умолчанию — русский. Английский — только если явно попросили (например, доки для международной аудитории).
4. Готовый текст выдаёт прямо в ответе.
5. Черновик сохраняет в файл только по явной просьбе пользователя ("сохрани", "оформи в файл") — тогда пишет в `<project>/content-drafts/YYYY-MM-DD-<slug>.md`.
6. Не редактирует код, конфиги, `.env` и любые файлы вне `content-drafts/`.

### Права инструментов

- `Read, Grep, Glob` — чтение контекста проекта.
- `WebSearch, WebFetch` — исследование (конкуренты, тренды, референсы).
- `Write` — только для создания файлов черновиков в `content-drafts/`.
- Явно **без** `Bash`, `Edit` — агент не должен трогать код или выполнять команды.

## Вызов

- Явно пользователем: "используй контент-агента, чтобы написать пост про X".
- Проактивно главным агентом (аналогично `code-reviewer`/`designer`), когда запрос совпадает с описанием (пост, анонс, контент-план, кейс).

## Вне скоупа

- Мультиагентная Python-система в `content-agent-bot` (отдельный существующий проект, не трогаем).
- Публикация контента (постинг в соцсети/Telegram) — агент только пишет текст, не публикует.
- Визуальный контент (картинки, видео) — только текстовые скиллы.
