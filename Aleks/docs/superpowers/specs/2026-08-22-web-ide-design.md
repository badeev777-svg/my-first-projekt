# Веб-IDE (Claude Code CLI в браузере) на Beget VPS

## Цель
Полноценный доступ к Claude Code через браузер с любого устройства (ноутбук, телефон, планшет): чат, терминал, файлы и git в одном окне — без необходимости в SSH-клиенте.

## Целевая инфраструктура
- Сервер: существующий Beget VPS, SSH-алиас `aleks-agent`, root-доступ есть.
- Проект: `/root/projects/Aleks` (этот репозиторий, уже деплоится туда через `deploy/deploy.sh`).
- Домен: под управлением пользователя, конкретный поддомен (например `ide.<домен>.ru`) — **решить перед началом работы**.
- Авторизация Claude: через аккаунт Claude.ai (не API-ключ).

## Архитектура
```
Браузер (любое устройство)
   ↓ HTTPS (443)
nginx (reverse proxy, TLS от Let's Encrypt на выбранном поддомене)
   ↓ localhost:8080
code-server (systemd-сервис, от НЕ-root пользователя webide)
   ↓ терминал (xterm.js) → `claude` CLI (залогинен в Claude.ai аккаунт)
   ↓ файлы/git — доступ к /root/projects/Aleks через ACL
```

## Компоненты
1. **nginx + certbot** — TLS-терминация на выбранном поддомене, автопродление сертификата.
2. **code-server** — под отдельным системным пользователем `webide` (не root), чтобы утечка пароля от IDE не давала root-доступ ко всему серверу. Доступ к `/root/projects/Aleks` — через `setfacl`, без переноса/дублирования проекта. Слушает только `127.0.0.1:8080`.
3. **Claude Code CLI** — глобальная установка (Node.js уже должен быть на сервере), логин через `claude login` — один раз интерактивно, ссылка кликается прямо в терминале code-server.
4. **Firewall (ufw)** — открыты только 22 (SSH), 80/443. Порт 8080 не выставлен наружу.
5. **Пароль code-server** — bcrypt-хэш в `config.yaml`, плюс `limit_req` в nginx против брутфорса.

## Права доступа
Проект остаётся на месте (`/root/projects/Aleks`), пользователь `webide` получает rwx через ACL. Существующий `deploy/deploy.sh` продолжает работать без изменений.

## Обработка ошибок
- code-server падает → systemd рестартует автоматически (`Restart=on-failure`).
- TLS-сертификат — автопродление через certbot systemd timer.
- Сессия Claude.ai истечёт — редкость; повторный `claude login` в терминале.

## Проверка после установки
1. Открыть `https://ide.<домен>` с телефона и с ноутбука.
2. Ввести пароль code-server.
3. Открыть терминал, запустить `claude`, убедиться что диалог работает.
4. Отредактировать файл, увидеть diff во встроенной git-панели, закоммитить.
