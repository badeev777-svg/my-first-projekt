# Веб-IDE (code-server + Claude Code CLI) на Beget VPS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Дать доступ к Claude Code через браузер с любого устройства (чат, терминал, файлы, git) на существующем Beget VPS (`aleks-agent` хост), для проекта `/root/projects/Aleks`.

**Architecture:** code-server (VS Code в браузере) под отдельным непривилегированным системным пользователем `webide` с ACL-доступом к `/root/projects/Aleks`, за nginx reverse proxy с TLS от Let's Encrypt на поддомене `ide.бизнесгенератор.рф`. Claude Code CLI ставится глобально и логинится через аккаунт Claude.ai внутри терминала code-server.

**Tech Stack:** code-server, Node.js 20.x, `@anthropic-ai/claude-code`, nginx, certbot, ufw, systemd, POSIX ACL.

**Ссылка на дизайн:** [`docs/superpowers/specs/2026-08-22-web-ide-design.md`](../specs/2026-08-22-web-ide-design.md)

**Ключевые факты:**
- SSH-хост: `aleks-agent` (уже настроен в `~/.ssh/config` локально).
- Путь проекта на сервере: `/root/projects/Aleks`.
- Домен: `бизнесгенератор.рф`. Поддомен для IDE: `ide.бизнесгенератор.рф`, в punycode для nginx/certbot: `ide.xn--80abghbakh0cdnwcgv.xn--p1ai`.
- Email для Let's Encrypt: `badeev777@gmail.com`.

- [ ] **Step 1: Написать `deploy/web-ide/setup.sh`**

```bash
#!/usr/bin/env bash
# deploy/web-ide/setup.sh
# Bootstraps code-server + Claude Code CLI on the aleks-agent VPS, exposed
# only to a dedicated non-root user (webide) via ACL so a leaked IDE
# password can't grant root shell access to the whole server.
# Run as root on the VPS: bash setup.sh
set -euo pipefail

PROJECT_DIR="/root/projects/Aleks"
WEBIDE_USER="webide"
WEBIDE_HOME="/home/${WEBIDE_USER}"

echo "==> Creating ${WEBIDE_USER} user (no shell login)"
if ! id "${WEBIDE_USER}" &>/dev/null; then
    useradd -m -s /usr/sbin/nologin "${WEBIDE_USER}"
fi

echo "==> Granting ACL access to ${PROJECT_DIR}"
apt-get install -y acl >/dev/null
setfacl -m u:${WEBIDE_USER}:x /root
setfacl -m u:${WEBIDE_USER}:x /root/projects
setfacl -R -m u:${WEBIDE_USER}:rwx "${PROJECT_DIR}"
setfacl -R -d -m u:${WEBIDE_USER}:rwx "${PROJECT_DIR}"

echo "==> Installing Node.js 20.x (if missing or too old)"
if ! command -v node &>/dev/null || [ "$(node -v | cut -d. -f1 | tr -d v)" -lt 18 ]; then
    curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
    apt-get install -y nodejs
fi

echo "==> Installing Claude Code CLI globally"
npm install -g @anthropic-ai/claude-code

echo "==> Installing code-server"
curl -fsSL https://code-server.dev/install.sh | sh

echo "==> Writing code-server config for ${WEBIDE_USER}"
mkdir -p "${WEBIDE_HOME}/.config/code-server"
CS_PASSWORD="$(openssl rand -base64 24)"
cat > "${WEBIDE_HOME}/.config/code-server/config.yaml" <<EOF
bind-addr: 127.0.0.1:8080
auth: password
password: ${CS_PASSWORD}
cert: false
EOF
chown -R "${WEBIDE_USER}:${WEBIDE_USER}" "${WEBIDE_HOME}/.config"
chmod 600 "${WEBIDE_HOME}/.config/code-server/config.yaml"

echo "==> code-server password (save this now, it is not printed again):"
echo "==> ${CS_PASSWORD}"
```

```bash
chmod +x deploy/web-ide/setup.sh
```

- [ ] **Step 2: Написать `deploy/web-ide/code-server-webide.service`**

```ini
# deploy/web-ide/code-server-webide.service
[Unit]
Description=code-server (web IDE) for webide user
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=webide
Group=webide
WorkingDirectory=/root/projects/Aleks
Environment=HOME=/home/webide
ExecStart=/usr/bin/code-server --config /home/webide/.config/code-server/config.yaml /root/projects/Aleks
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

- [ ] **Step 3: Написать `deploy/web-ide/nginx-ratelimit.conf`**

```nginx
# deploy/web-ide/nginx-ratelimit.conf
# Goes into /etc/nginx/conf.d/ — defines the zone used by nginx-ide-aleks.conf.
limit_req_zone $binary_remote_addr zone=ide_login:10m rate=5r/s;
```

- [ ] **Step 4: Написать `deploy/web-ide/nginx-ide-aleks.conf`**

```nginx
# deploy/web-ide/nginx-ide-aleks.conf
# Goes into /etc/nginx/sites-available/, symlinked into sites-enabled/.
# certbot --nginx will rewrite this file in place to add the ssl/redirect blocks.
server {
    listen 80;
    server_name ide.xn--80abghbakh0cdnwcgv.xn--p1ai;

    location / {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host $host;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection upgrade;
        proxy_set_header Accept-Encoding gzip;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        limit_req zone=ide_login burst=10 nodelay;
    }
}
```
