# Lead Parser — Спецификация

## Краткое описание
Система автоматического мониторинга и сбора заявок на разработку и продвижение сайтов из публичных источников. Агрегирует лиды в веб-дашборд, рассылает уведомления через Telegram-бот и Email. Использует один человек.

---

## Проблема
Вручную мониторить Telegram-каналы, Avito, фриланс-биржи и VK несколько раз в день — трудоёмко. Подходящие заявки теряются или находятся с опозданием. Инструментов для автоматизации нет.

## Критерии успеха
- Новые подходящие заявки появляются в дашборде в течение 5–15 минут после публикации
- Уведомление приходит без ручного обновления страниц
- Дубликаты не появляются повторно

---

## Пользователь
- **Один человек** — владелец / фрилансер, работает с заявками самостоятельно
- Технический уровень: средний (может развернуть сервер по инструкции)
- Авторизация: не нужна на MVP

---

## Источники мониторинга

### P0 — Старт (лёгкие, дают ~80% заявок)

| Источник | Метод | Примечание |
|----------|-------|------------|
| Telegram-каналы/группы | Telethon (userbot) | Читает публичные каналы по ключевым словам |
| FL.ru | RSS-фид новых проектов | Простой XML, без парсинга HTML |
| Habr Freelance | RSS-фид / парсинг HTML | Качественные IT-заказы |

### P1 — Второй этап

| Источник | Метод | Примечание |
|----------|-------|------------|
| Kwork | Парсинг HTML | Нет RSS, нужен httpx + BS4 |
| Freelance.ru | Парсинг HTML | Аналогично FL.ru |
| Weblancer.net | Парсинг HTML | Специализация на IT |
| YouDo | Парсинг HTML | Категория «сайты» |
| VK группы | VK API (wall.search) | Поиск по ключевым словам |

### P2 — Будущее

| Источник | Метод | Примечание |
|----------|-------|------------|
| Avito | Парсинг HTML | Cloudflare / captcha — сложно |
| Profi.ru | Парсинг HTML | Закрытый API, только скрапинг |

## Критерии фильтрации

**По ключевым словам** (настраиваемый список), примеры:
- «сделайте сайт», «нужен сайт», «разработка сайта»
- «продвижение», «SEO», «контекстная реклама»
- «лендинг», «интернет-магазин», «верстка»

**По бюджету** (опционально):
- Минимальный порог в рублях
- Игнорировать, если бюджет явно ниже порога

## Модель данных — Lead

```
id            UUID
source        enum: telegram | fl | habr | kwork | freelance | weblancer | youdo | vk | avito | profi
source_url    string (ссылка на оригинал)
text          text (текст заявки/сообщения)
budget        int? (если указан, в рублях)
contact       string? (Telegram username / телефон / email)
created_at    datetime (когда опубликовано)
fetched_at    datetime (когда подобрано парсером)
status        enum: new | viewed | archived
```

## Функциональные требования

### P0 — MVP (обязательно)
- [ ] Мониторинг Telegram-каналов по ключевым словам — новый лид в БД при совпадении
- [ ] Парсинг FL.ru через RSS-фид
- [ ] Парсинг Habr Freelance через RSS / HTML
- [ ] Веб-дашборд: список лидов, сортировка по дате, статус (новый / просмотрен)
- [ ] Просмотр карточки лида: текст, источник, контакт, бюджет, ссылка
- [ ] Уведомление в Telegram-бот при каждом новом лиде
- [ ] Дедупликация (один и тот же URL / message_id не добавляется дважды)

### P1 — Следующий этап
- [ ] Парсинг Kwork, Freelance.ru, Weblancer.net, YouDo
- [ ] VK API: поиск по ключевым словам в группах
- [ ] Email-уведомления
- [ ] Фильтр по бюджету в UI
- [ ] Поиск по тексту в дашборде
- [ ] Архивирование / удаление лидов

### P2 — Будущее
- [ ] Парсинг Avito (требует обход rate-limit)
- [ ] Profi.ru скрапинг
- [ ] Статистика: сколько лидов в день / по источникам
- [ ] Авторизация (если к системе добавятся другие пользователи)

## Техническая архитектура

### Стек (рекомендуемый)
- **Backend**: Python + FastAPI
- **Парсинг Telegram**: Telethon (userbot, читает публичные каналы)
- **Парсинг сайтов**: httpx + BeautifulSoup / Playwright (если JS-рендеринг)
- **БД**: SQLite (MVP) → PostgreSQL (при росте)
- **Планировщик**: APScheduler или простой cron
- **Frontend**: HTML + Alpine.js + Tailwind (без отдельного SPA)
- **Telegram-бот (уведомления)**: aiogram 3

## Нефункциональные требования
- **Latency**: новый лид в дашборде ≤ 15 минут после публикации
- **Rate-limiting**: паузы между запросами к внешним сайтам (min 3–5 сек)
- **Надёжность**: если парсер упал — не теряем данные, при следующем запуске догоняем
- **Хранение**: лиды хранятся бессрочно, архивирование вручную

## Приложение: исследования
- **Telethon vs. Telegram Bot API**: Telethon (userbot) позволяет читать публичные каналы без добавления бота; Bot API требует, чтобы бот был добавлен в канал. Для мониторинга публичных каналов — Telethon предпочтительнее.
- **FL.ru**: Имеет RSS для новых проектов — простейший способ мониторинга без парсинга HTML. URL: `https://www.fl.ru/rss/all.xml?category=разработка`
- **Habr Freelance**: RSS-фид активных проектов, качественная аудитория IT-специалистов.
- **Kwork**: Нет публичного RSS, нужен парсинг HTML или имитация браузера. Отложить до P1.
- **Weblancer.net**: Старейшая русская биржа, специализация на IT. Парсинг HTML, P1.
- **YouDo**: Есть категория «разработка сайтов». Парсинг HTML, P1.
- **VK API**: `wall.search` позволяет искать посты по ключевым словам в публичных группах. P1.
- **Avito**: Сильная защита от парсинга (Cloudflare, captcha). Рекомендую отложить до P2.
- **Profi.ru**: Закрытый API, только скрапинг. P2.
