Логика экрана

Название — обязательное поле, текстовый ввод

Дата — по умолчанию выбранный день из главного экрана, можно изменить через date picker

Время — необязательно. Если указано:

  • Уведомление в 9:00 в день задачи
  • Уведомление за 1 час до начала

Если время не указано — только утреннее уведомление в 9:00

Сохранить — записывает в Room DB, планирует уведомления через WorkManager
