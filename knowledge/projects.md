## 🤖 SpeakBuddy – AI-тьютор разговорного английского

**Статус:** ✅ Phase 1 + Phase 2 готовы  
**Тип:** Telegram-бот + Claude API  
**Стек:** Python, Telegram Bot API, Claude 3.5, asyncio  
**Монетизация:** Тарифная модель  

### Описание
Телеграм-бот для практики разговорного английского с AI-наставником. Пользователь пишет или читает текст, агент реагирует, исправляет ошибки, предлагает альтернативы и подсказки.

### Реализовано (Phase 1+2)
- ✅ Базовый диалог с Claude
- ✅ Коррекция грамматики и произношения
- ✅ Система тарифов (free, pro, premium)
- ✅ Async обработка сообщений
- ✅ Интеграция платежей
- ✅ Security-проверки

### Следующие шаги
- Метрики анализа уровня студента
- Персонализированные уроки по тематикам
- Аудио-ввод (speech-to-text)

## 📦 Content Agent Bot – мультиагентный SMM-помощник

**Статус:** 🔧 Разработка в процессе  
**Тип:** Telegram-бот + мультиагентная система  
**Стек:** Python, FastAPI, PostgreSQL, Claude API, Telegram API  
**Монетизация:** 2499 ₽ + 3 переписывания/день  

### Описание
Telegram-бот для small business и SMM-агентств. Генерирует контент, переписывает посты, анализирует аудиторию, рекомендует хэштеги и время публикации. **Мультиагентная архитектура:** одновременно работают Creator Agent, Editor Agent, Analyzer Agent.

### Реализовано
- ✅ Спецификация проекта
- ✅ Система дневных лимитов на переписывание (check_rewrite_allowed)
- ✅ PostgreSQL для хранения квот и истории
- ✅ Pricing model с расчётом break-even
- ✅ Deployment готов (Beget хостинг, Docker)

### Текущие работы
- Проверка bot startup на Beget
- Интеграция всех 3 агентов в обработчик сообщений
- Тестирование лимитов и квот

## 👗 primerka – Virtual Try-On App

**Статус:** 🔄 Active development  
**Тип:** FastAPI backend + ML интеграция  
**Стек:** Python, FastAPI, HuggingFace (free tier), OpenCV  
**Монетизация:** SaaS для e-commerce  

### Описание
Приложение для виртуальной примерки одежды. Пользователь загружает фото себя, выбирает вещь из каталога — агент генерирует preview, как это будет выглядеть.

### Реализовано
- ✅ FastAPI backend
- ✅ HuggingFace free tier интеграция (with binary transport, не base64!)
- ✅ Image upload и обработка
- ✅ Обёрнуто в Docker

### Текущие работы
- Оптимизация скорости обработки
- Интеграция с e-commerce платформами

### Важные уроки
- ❌ НИКОГДА не использовать base64 JSON с HF API
- ✅ ВСЕГДА использовать InferenceClient с binary transport
