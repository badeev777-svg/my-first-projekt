# Конкурентное исследование: ИИ-агенты для генерации контента в SMM

> Основа: идея бота, который принимает URL → генерирует 21 пост на неделю (7 дней × Telegram + VC.ru + Сторис) с хэштегами, CTA и временем публикации. Аудитория: маркетологи, копирайтеры, SMM-специалисты.

---

## Главный вывод (TL;DR)

**Ниша свободна.** Ни один из 10+ изученных продуктов не реализует механику «вставь URL → получи 21 структурированный пост на неделю для Telegram + VC.ru + Сторис» с нативной поддержкой русского языка прямо в Telegram-боте. Это прямое окно входа.

## 1. Lately.ai (США)

**Тип:** веб-сервис | **Цена:** $99–179/мес.

### Задача
Переупаковка длинного контента (статьи, видео, подкасты) в десятки готовых постов для соцсетей.

### Ключевые функции
- URL или файл → транскрипция → разбивка на фрагменты → 10–100+ вариантов постов
- **Voice Model** — обучается на истории публикаций аккаунта, тиражирует паттерны высокоэффективных постов
- Контент-календарь + очередь планирования
- Approval workflow для командной работы

### Типичный диалог / путь пользователя
```
1. Вставляет URL статьи или загружает видео
2. Lately транскрибирует + извлекает ключевые фрагменты
3. Voice Model адаптирует под голос бренда
4. Получает пачку готовых постов с предпросмотром под каждую платформу
5. Выбирает нужные, ставит в расписание
6. Аналитика → Voice Model обновляется
```

### Что делает его сильным
- Единственный с нейросетевым обучением на голосе бренда через исторические данные
- Работает с богатыми медиаформатами (видео, подкасты)

### Что взять в наш бот
- Концепция «один источник → батч постов» — подтверждённый спрос
- Разбивка длинного текста на атомарные фрагменты перед генерацией
- Voice Model как roadmap v2: бот запоминает стиль пользователя

## 2. Blaze.ai (США)

**Тип:** веб-сервис | **Цена:** $25–99/мес.

### Задача
«AI-маркетолог» — принимает URL статьи, PDF или YouTube-ссылку и генерирует контент по 50+ шаблонам для разных платформ.

### Ключевые функции
- URL → веб-скрапинг → 50+ форматов за один запрос
- **Brand Voice** — обучается на текстах пользователя, воспроизводит его стиль
- Поддержка LinkedIn, Facebook, Instagram, TikTok, X, WordPress, email
- Встроенный планировщик публикаций

### Типичный диалог / путь пользователя
```
1. Вставляет URL статьи конкурента
2. Выбирает нужные форматы из библиотеки
3. AI генерирует адаптированные версии для каждой платформы
4. Редактирует (20–30% случаев требует правки)
5. Планирует публикацию через встроенный планировщик
```

### Что делает его сильным
- Ближайший аналог нашей механики «URL → N постов»
- Хорошая платформенная адаптация тона: LinkedIn = профессиональный, Instagram = визуальный крючок
- Из 1 блог-поста — 10+ постов за минуты

### Слабые стороны
- Нет Telegram и VC.ru как выходных платформ
- 50 форматов — перегруз, пользователи теряются
- Нет русского языка

### Что взять в наш бот
- Чёткий фокус на 3 платформах против 50 — наше преимущество
- Brand Voice как обязательный roadmap v2
- Отдельные промпты с разными инструкциями под каждую платформу

## 3. ContentStudio (Международный)

**Тип:** веб-платформа | **Цена:** $25–99/мес. | **Freemium:** 14 дней без карты

### Задача
Комплексная автоматизация SMM: обнаружение контента → генерация → планирование → аналитика.

### Ключевые функции
- AI Studio: URL → мета-извлечение → посты с хэштегами и эмодзи, несколько вариантов тональности
- Automation Recipes: автопубликация из RSS-лент
- Evergreen recycling: переиздание вечнозелёного контента по расписанию
- Визуальный контент-календарь

### Типичный диалог / путь пользователя
```
1. Вставляет URL в AI Studio
2. Инструмент автоматически извлекает заголовок и описание
3. Нажимает «Generate» → несколько вариантов поста с хэштегами
4. Выбирает платформы, добавляет медиа
5. Ставит в расписание через визуальный календарь
```

### Что взять в наш бот
- URL → автоизвлечение мета-данных как первый шаг перед генерацией
- Несколько вариантов одного поста на выбор пользователя
- Хэштеги и эмодзи как встроенная часть output, не опция

## 4. SMMplanner + бот @SMMGenaBot (Россия)

**Тип:** веб-сервис + Telegram-бот | **Цена:** от 399 руб/мес | **Freemium:** да

### Задача
SMMplanner — планирование и публикация с AI-ассистентом. @SMMGenaBot — бесплатная «витрина»: случайные идеи и хэштеги прямо в Telegram.

### Ключевые функции
**SMMplanner (веб):**
- Автопостинг в Telegram, ВКонтакте, Instagram и др.
- AI-ассистент прямо в форме создания поста

**@SMMGenaBot (Telegram, бесплатно):**
- Случайные идеи для постов и сторис (150+ тем)
- Подбор хэштегов по ключевому слову и по фото
- Поиск хэштегов конкурентов

### Типичный диалог / путь пользователя
```
Пользователь:  /start
Геннадий:       Что хочешь сделать?
                [💡 Идея для поста] [#️⃣ Хэштеги] [🖼 Генерация фото]

Пользователь:  [💡 Идея для поста]
Геннадий:       Тема: разбор частой ошибки клиентов.
                Пример: «Расскажите, как клиент сэкономил 40 тыс.,
                когда вовремя обратился к вам.»
```

### Что делает его сильным
- Бесплатный Telegram-бот как «витрина» для платного продукта
- Замкнутый цикл: идея (Геннадий) → текст (AI) → публикация (SMMplanner)
- Поддержка российских платформ (ОК, ВКонтакте, Telegram)

### Слабые стороны
- Геннадий выдаёт только идею/тему, не готовый пост
- Нет работы с URL
- Контент-план не генерируется пакетом — каждый пост отдельно

### Что взять в наш бот
- Модель «бесплатный бот-витрина → платная подписка»
- Интеграция AI прямо в форму без переключения контекста
- Случайные темы как fallback, когда URL нет

## 5. AI-SMM.ru (Россия)

**Тип:** веб-сервис | **Цена:** от 450 руб/мес | **Freemium:** 7 дней без карты

### Задача
Полная автоматизация SMM для малого бизнеса: стратегия → тексты → публикация → ТЗ на визуал.

### Ключевые функции
- Анализ конкурентов по ссылкам на их соцсети → контент-план с учётом их рабочих форматов
- Контент-план на месяц для каждой соцсети отдельно
- ТЗ на фото и видео для каждого поста
- Поддержка 13 соцсетей (ВКонтакте, Telegram, ОК, TikTok и др.)
- Российские серверы

### Типичный диалог / путь пользователя
```
1. Указывает: "Ниша: продажа цветов. ВКонтакте + Telegram."
2. Добавляет ссылки на 3 конкурента
3. AI анализирует их аккаунты за последние 30 дней
4. Через 2–5 мин получает контент-план: темы, форматы, ТЗ на фото/видео
5. Редактирует черновики → публикует по расписанию
```

### Что делает его сильным
- Единственный, кто явно анализирует конкурентов для формирования плана
- ТЗ на визуал — закрывает вопрос «что снимать», не только «что писать»

### Слабые стороны
- Нет Telegram-бота — только веб
- Ввод конкурентов требует ссылок на аккаунты в соцсетях, а не произвольного URL

### Что взять в наш бот
- Анализ конкурентов как сценарий входа (наш бот это поддерживает)
- ТЗ на визуал как дополнительный output к посту (roadmap v2)
- Раздельные форматы под каждую площадку в одном плане

Система: Что вы продаёте?
Пользователь: Онлайн-курсы по дизайну
Система: Кто ваш клиент? Какие главные возражения?
...

→ Клик на день → выбор формата (пост / сторис / сценарий)

### Что делает его сильным
- Стратегическая воронка внутри контент-плана
- Адаптация одного смысла под несколько форматов

### Слабые стороны
- Нет Telegram-бота, нет работы с URL
- Длинный онбординг (10–15 мин до первого результата)

### Что взять в наш бот

- 3–5 онбординг-вопросов перед генерацией = резкий рост качества output
- Адаптация одного смысла под Telegram, VC.ru и Сторис — именно наша механика

## Ключевые инсайты для спецификации

### 1. УТП подтверждено рынком
Ни один продукт не даёт «URL → 21 пост на неделю (Telegram + VC.ru + Сторис)» с русскоязычным контентом в Telegram-боте. Это незанятая ниша с подтверждённым спросом.

### 2. UX-паттерн, который работает
Все успешные продукты используют: **вход (URL) → минимум параметров → пакет постов → выбор/редактирование**. Не длинный диалог, а быстрый результат. Максимум 3–5 вопросов перед генерацией.

### 3. Платформенная адаптация — главный дифференциатор
Продукты без адаптации тона получают отзывы «generic, robotic». Telegram, VC.ru и Сторис — разные жанры:
- **Telegram**: лаконично, личный голос, без корпоратизма
- **VC.ru**: развёрнутый тезис с доказательствами
- **Сторис**: 3 слова + визуальный крючок, эмодзи

Нужны отдельные системные промпты с инструкциями под каждую платформу.

### 4. Стратегическая воронка внутри недели
Вместо 7 одинаковых постов — структурированный mix:
- День 1–2: вовлечение (вопрос, провокация)
- День 3–4: экспертиза (факт, кейс)
- День 5–6: доверие (отзыв, история)
- День 7: продажа (CTA, оффер)

### 5. Монетизация в рунете
- Freemium: 3–5 бесплатных генераций (не целая неделя) → подписка
- Flat fee 499–799 руб/мес — оптимальный диапазон
- 7 дней полного доступа бесплатно — стандарт рынка

### 6. Retention-механики
- Уведомления внутри Telegram — нулевое трение (лучший канал для retention)
- Бесплатный бот-витрина с базовыми функциями → конвертация в платную подписку (модель Геннадия)

### 7. Диалоговая доработка
После генерации — кнопки быстрого редактирования: «Переписать», «Короче», «Формальнее». Снижает недовольство качеством без выхода из бота.

### 8. Brand Voice — roadmap v2
Все лидеры, кто реализовал обучение на текстах пользователя (Lately Voice Model, Blaze Brand Voice, Supergrow Content DNA), получили резкий рост воспринимаемого качества и retention. Это ключевая функция для второй версии.
