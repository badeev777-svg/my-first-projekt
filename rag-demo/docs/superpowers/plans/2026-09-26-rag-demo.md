# RAG-демо «Ответы по документам» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Веб-демо для встреч с клиентами: загрузка PDF/DOCX → ответы строго по документам со ссылками `[файл, стр. N]`, сессии в памяти удаляются через 1 час.

**Architecture:** FastAPI-сервис без БД. Текст извлекается локально (pypdf, python-docx), режется на куски, векторизуется через cloud.ru (`BAAI/bge-m3`), ищется косинусом в numpy, пересортировывается реранкером (`BAAI/bge-reranker-v2-m3`), ответ генерирует GigaChat (`ai-sage/GigaChat3.5-432B-A28B`) только по 5 лучшим фрагментам. Одна статическая HTML-страница.

**Tech Stack:** Python ≥3.12, uv, FastAPI, uvicorn, httpx, numpy, pypdf, python-docx, pydantic-settings, python-multipart; тесты — pytest, fpdf2 (генерация PDF в тестах).

**Spec:** `rag-demo/docs/superpowers/specs/2026-09-26-rag-demo-design.md`

## Проверенные факты об API cloud.ru (2026-09-26, живые запросы)

- Base URL: `https://foundation-models.api.cloud.ru/v1`, заголовок `Authorization: Bearer <key>`.
- `POST /embeddings` `{"model":"BAAI/bge-m3","input":[...]}` → OpenAI-формат, `data[i].embedding`, размерность **1024**.
- `POST /rerank` `{"model":"BAAI/bge-reranker-v2-m3","query":"...","documents":[...],"top_n":N}` → `{"results":[{"index":int,"document":{"text":...},"relevance_score":float}, ...]}`, отсортировано по убыванию score, `top_n` работает. (`/v1/rerank` и `/score` → 404.)
- `POST /chat/completions` — OpenAI-совместимый (так уже работает `lead-parser/app/analyzer.py`).
- Ключ: значение `GIGACHAT_API_KEY` из `lead-parser/.env`.
- **НЕ проверено:** максимальный размер пачки `input` у `/embeddings` (в плане 32 — наш выбор, не лимит API). Если на живом прогоне (Task 9) придёт 4xx на пачке — уменьшить `EMBED_BATCH` и записать факт в `PLAN.md`.

## Global Constraints

- Форматы v1: только PDF и DOCX; сообщение для прочих — «Поддерживаются PDF и DOCX.»
- PDF без текста — «Похоже, это скан. Распознавание сканов появится в следующей версии.»
- cloud.ru недоступен (после 1 повтора) — «Сервис ИИ временно недоступен, попробуйте через минуту.»
- Сессия истекла — «Сессия завершена, документы удалены. Загрузите их снова.»
- Нет ответа в документах — ровно «В загруженных документах этого нет.»
- Лимиты по умолчанию: 10 файлов/сессию, 20 МБ/файл, 60 вопросов/сессию, TTL сессии 3600 с, очистка каждые 300 с.

- Ключ и код доступа только в `.env`; `.env` в `.gitignore`.
- Cookie сессии: HttpOnly, SameSite=Strict, Secure (кроме локальной разработки).
- 4xx от cloud.ru не повторяем (ошибки ключа/биллинга), 5xx и сетевые — 1 повтор.

from io import BytesIO

import docx
from fpdf import FPDF


def make_pdf(pages: list[str]) -> bytes:
    """ASCII-only: встроенный шрифт fpdf не поддерживает кириллицу."""
    pdf = FPDF()
    pdf.set_font("Helvetica", size=12)
    for text in pages:
        pdf.add_page()
        if text:
            pdf.cell(text=text)
    return bytes(pdf.output())


def make_docx(paragraphs: list[str]) -> bytes:
    document = docx.Document()
    for text in paragraphs:
        document.add_paragraph(text)
    buf = BytesIO()
    document.save(buf)
    return buf.getvalue()
```

from dataclasses import dataclass
from io import BytesIO

import docx
from pypdf import PdfReader


class ExtractError(Exception):
    """Сообщение показывается пользователю как есть."""


class UnsupportedFormat(ExtractError):
    pass


class NoTextLayer(ExtractError):
    pass


@dataclass(frozen=True)
class Unit:
    file: str
    kind: str  # "стр." для PDF, "абз." для DOCX — в DOCX нет страниц
    num: int
    text: str


def extract(filename: str, data: bytes) -> list[Unit]:
    ext = filename.rsplit(".", 1)[-1].lower() if "." in filename else ""
    if ext == "pdf":
        return _pdf(filename, data)
    if ext == "docx":
        return _docx(filename, data)
    raise UnsupportedFormat("Поддерживаются PDF и DOCX.")


def _pdf(filename: str, data: bytes) -> list[Unit]:
    try:
        reader = PdfReader(BytesIO(data))
        if reader.is_encrypted:
            raise ExtractError(f"Файл «{filename}» защищён паролем.")
        units = [
            Unit(filename, "стр.", i, text)
            for i, page in enumerate(reader.pages, start=1)
            if (text := (page.extract_text() or "").strip())
        ]
    except ExtractError:
        raise
    except Exception as e:
        raise ExtractError(f"Не удалось прочитать файл «{filename}».") from e
    if not units:
        raise NoTextLayer("Похоже, это скан. Распознавание сканов появится в следующей версии.")
    return units


def _docx(filename: str, data: bytes) -> list[Unit]:
    try:
        document = docx.Document(BytesIO(data))
    except Exception as e:
        raise ExtractError(f"Не удалось прочитать файл «{filename}».") from e
    units = [
        Unit(filename, "абз.", i, text)
        for i, p in enumerate(document.paragraphs, start=1)
        if (text := p.text.strip())
    ]
    if not units:
        raise NoTextLayer(f"В файле «{filename}» нет текста.")
    return units
```

```python
from dataclasses import dataclass
from itertools import groupby

from app.extract import Unit


@dataclass(frozen=True)
class Chunk:
    file: str
    loc: str
    text: str


def chunk_units(units: list[Unit], size: int = 800, overlap: int = 150) -> list[Chunk]:
    if not 0 <= overlap < size:
        raise ValueError("overlap must be in [0, size)")
    chunks: list[Chunk] = []
    # Фрагмент не пересекает границу файла — иначе ссылка на источник будет неверной.
    for _, group in groupby(units, key=lambda x: x.file):
        chunks.extend(_chunk_file(list(group), size, overlap))
    return chunks


def _loc(kind: str, first: int, last: int) -> str:
    return f"{kind} {first}" if first == last else f"{kind} {first}–{last}"


def _windows(text: str, size: int, overlap: int) -> list[str]:
    step = size - overlap
    return [text[i : i + size] for i in range(0, max(len(text) - overlap, 1), step)]


def _chunk_file(units: list[Unit], size: int, overlap: int) -> list[Chunk]:
    out: list[Chunk] = []
    buf: list[Unit] = []
    buf_len = 0

    def flush() -> None:
        nonlocal buf, buf_len
        if buf:
            out.append(
                Chunk(buf[0].file, _loc(buf[0].kind, buf[0].num, buf[-1].num), "\n".join(x.text for x in buf))
            )
            buf, buf_len = [], 0

    for unit in units:
        if len(unit.text) > size:
            flush()
            out.extend(Chunk(unit.file, _loc(unit.kind, unit.num, unit.num), piece)
                       for piece in _windows(unit.text, size, overlap))
            continue
        extra = len(unit.text) + (1 if buf else 0)
        if buf and buf_len + extra > size:
            flush()
            extra = len(unit.text)
        buf.append(unit)
        buf_len += extra
    flush()
    return out
```

```python
import time

import httpx
import numpy as np

from app.config import Settings

EMBED_BATCH = 32


class CloudRuError(Exception):
    pass


class CloudRuClient:
    def __init__(self, settings: Settings, http: httpx.Client | None = None, retry_delay: float = 1.0):
        self._s = settings
        self._http = http or httpx.Client(base_url=settings.cloudru_base_url, timeout=settings.http_timeout_seconds)
        self._headers = {"Authorization": f"Bearer {settings.cloudru_api_key}"}
        self._retry_delay = retry_delay

    def _post(self, path: str, payload: dict) -> dict:
        err: Exception | None = None
        for attempt in (1, 2):
            try:
                r = self._http.post(path, json=payload, headers=self._headers)
            except httpx.TransportError as e:
                err = e
            else:
                # 4xx — ключ/биллинг/запрос: повтор не поможет и может списать деньги дважды.
                if 400 <= r.status_code < 500:
                    raise CloudRuError(f"cloud.ru HTTP {r.status_code}")
                if r.status_code < 400:
                    return r.json()
                err = CloudRuError(f"cloud.ru HTTP {r.status_code}")
            if attempt == 1:
                time.sleep(self._retry_delay)
        raise CloudRuError("cloud.ru unavailable") from err

    def embed(self, texts: list[str]) -> np.ndarray:
        vectors: list[list[float]] = []
        for i in range(0, len(texts), EMBED_BATCH):
            data = self._post("/embeddings", {"model": self._s.embed_model, "input": texts[i : i + EMBED_BATCH]})
            items = sorted(data["data"], key=lambda x: x.get("index", 0))
            vectors.extend(item["embedding"] for item in items)
        return np.asarray(vectors, dtype=np.float32)

    def rerank(self, query: str, documents: list[str], top_n: int) -> list[tuple[int, float]]:
        data = self._post(
            "/rerank",
            {"model": self._s.rerank_model, "query": query, "documents": documents, "top_n": top_n},
        )
        return [(r["index"], r["relevance_score"]) for r in data["results"]]

    def chat(self, system: str, user: str) -> str:
        data = self._post(
            "/chat/completions",
            {
                "model": self._s.chat_model,
                "messages": [{"role": "system", "content": system}, {"role": "user", "content": user}],
                "temperature": 0.1,
            },
        )
        return data["choices"][0]["message"]["content"].strip()
```

```python
import secrets
import threading
import time
from collections.abc import Callable
from dataclasses import dataclass, field

import numpy as np

from app.chunker import Chunk


@dataclass
class Session:
    id: str
    created_at: float
    files: list[str] = field(default_factory=list)
    chunks: list[Chunk] = field(default_factory=list)
    vectors: np.ndarray | None = None
    questions: int = 0


class SessionStore:
    # Синхронные эндпоинты FastAPI выполняются в пуле потоков — нужен лок.
    def __init__(self, ttl_seconds: int, clock: Callable[[], float] = time.monotonic):
        self._ttl = ttl_seconds
        self._clock = clock
        self._sessions: dict[str, Session] = {}
        self._lock = threading.Lock()

    def _expired(self, s: Session) -> bool:
        return self._clock() - s.created_at > self._ttl

    def create(self) -> Session:
        s = Session(id=secrets.token_urlsafe(32), created_at=self._clock())
        with self._lock:
            self._sessions[s.id] = s
        return s

    def get(self, sid: str) -> Session | None:
        with self._lock:
            s = self._sessions.get(sid)
            if s is not None and self._expired(s):
                del self._sessions[sid]
                return None
            return s

    def add_document(self, session: Session, filename: str, chunks: list[Chunk], vectors: np.ndarray) -> None:
        with self._lock:
            session.files.append(filename)
            session.chunks.extend(chunks)
            session.vectors = vectors if session.vectors is None else np.vstack([session.vectors, vectors])

    def delete(self, sid: str) -> None:
        with self._lock:
            self._sessions.pop(sid, None)

    def purge_expired(self) -> int:
        with self._lock:
            dead = [sid for sid, s in self._sessions.items() if self._expired(s)]
            for sid in dead:
                del self._sessions[sid]
            return len(dead)

    def __len__(self) -> int:
        with self._lock:
            return len(self._sessions)
```

```python
from dataclasses import dataclass

import numpy as np

from app.session_store import Session

NOT_FOUND = "В загруженных документах этого нет."

SYSTEM_PROMPT = f"""Ты — ассистент, который отвечает на вопросы строго по фрагментам документов компании.
Правила:
1. Используй только информацию из фрагментов. Не добавляй знаний извне и не делай предположений.
2. После каждого утверждения ставь номер фрагмента-источника в квадратных скобках, например [1] или [2][3].
3. Если во фрагментах нет ответа на вопрос, ответь ровно фразой: «{NOT_FOUND}»
4. Отвечай по-русски, кратко и по делу."""


class NoDocuments(Exception):
    pass


@dataclass(frozen=True)
class Source:
    n: int
    file: str
    loc: str
    text: str


@dataclass(frozen=True)
class Answer:
    text: str
    sources: list[Source]


def _top_k(matrix: np.ndarray, query: np.ndarray, k: int) -> list[int]:
    m = matrix / np.linalg.norm(matrix, axis=1, keepdims=True)
    q = query / np.linalg.norm(query)
    scores = m @ q
    return [int(i) for i in np.argsort(-scores, kind="stable")[: min(k, len(scores))]]


def _user_prompt(question: str, sources: list[Source]) -> str:
    fragments = "\n\n".join(f"[{s.n}] ({s.file}, {s.loc})\n{s.text}" for s in sources)
    return f"Фрагменты документов:\n\n{fragments}\n\nВопрос: {question}"


def answer(client, session: Session, question: str, top_k: int = 20, top_n: int = 5) -> Answer:
    if not session.chunks or session.vectors is None:
        raise NoDocuments
    q = client.embed([question])[0]
    candidates = _top_k(session.vectors, q, top_k)
    ranked = client.rerank(question, [session.chunks[i].text for i in candidates], top_n=min(top_n, len(candidates)))
    picked = [session.chunks[candidates[idx]] for idx, _ in ranked]
    sources = [Source(n, c.file, c.loc, c.text) for n, c in enumerate(picked, start=1)]

    text = client.chat(SYSTEM_PROMPT, _user_prompt(question, sources))
    if NOT_FOUND.rstrip(".") in text:
        return Answer(NOT_FOUND, [])
    # Показываем только то, на что модель сослалась: несвязанные фрагменты создают ложное впечатление обоснованности.
    return Answer(text, [s for s in sources if f"[{s.n}]" in text])
```

import asyncio
import logging
import secrets
from contextlib import asynccontextmanager
from dataclasses import asdict
from pathlib import Path

from fastapi import Cookie, Depends, FastAPI, File, HTTPException, Request, Response, UploadFile
from fastapi.responses import FileResponse, JSONResponse
from pydantic import BaseModel, Field

from app.chunker import chunk_units
from app.cloudru import CloudRuClient, CloudRuError
from app.config import Settings
from app.extract import ExtractError, extract
from app.rag import NoDocuments
from app.rag import answer as rag_answer
from app.session_store import Session, SessionStore

log = logging.getLogger("rag-demo")

COOKIE = "sid"
PURGE_INTERVAL_SECONDS = 300
INDEX_HTML = Path(__file__).parent / "static" / "index.html"
SESSION_EXPIRED = "Сессия завершена, документы удалены. Загрузите их снова."


class LoginIn(BaseModel):
    code: str


class AskIn(BaseModel):
    question: str = Field(min_length=1, max_length=2000)


def create_app(settings: Settings, client=None, store: SessionStore | None = None) -> FastAPI:
    client = client or CloudRuClient(settings)
    store = store or SessionStore(settings.session_ttl_seconds)
    max_bytes = settings.max_file_mb * 1024 * 1024

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        async def purger():
            while True:
                await asyncio.sleep(PURGE_INTERVAL_SECONDS)
                if n := store.purge_expired():
                    log.info("purged %d expired sessions", n)

        task = asyncio.create_task(purger())
        yield
        task.cancel()

    app = FastAPI(lifespan=lifespan, docs_url=None, redoc_url=None, openapi_url=None)

    @app.exception_handler(CloudRuError)
    async def cloud_error(request: Request, exc: CloudRuError):
        log.warning("cloud.ru error: %s", exc)
        return JSONResponse(status_code=503, content={"detail": "Сервис ИИ временно недоступен, попробуйте через минуту."})

    def current_session(sid: str | None = Cookie(default=None)) -> Session:
        session = store.get(sid) if sid else None
        if session is None:
            raise HTTPException(401, SESSION_EXPIRED)
        return session

    @app.get("/")
    def index():
        return FileResponse(INDEX_HTML)

    @app.post("/api/login")
    def login(body: LoginIn, response: Response):
        if not secrets.compare_digest(body.code.encode(), settings.access_code.encode()):
            raise HTTPException(401, "Неверный код доступа.")
        session = store.create()
        response.set_cookie(
            COOKIE, session.id, httponly=True, secure=settings.cookie_secure,
            samesite="strict", max_age=settings.session_ttl_seconds,
        )
        return {"ok": True}

    @app.get("/api/session")
    def session_info(session: Session = Depends(current_session)):
        return {"files": session.files, "questions_left": settings.max_questions - session.questions}

    @app.post("/api/upload")
    def upload(files: list[UploadFile] = File(...), session: Session = Depends(current_session)):
        added = []
        for f in files:
            name = f.filename or "без имени"
            if len(session.files) >= settings.max_files:
                raise HTTPException(400, f"Можно загрузить не больше {settings.max_files} файлов.")
            if name in session.files:
                raise HTTPException(400, f"Файл «{name}» уже загружен.")
            data = f.file.read(max_bytes + 1)
            if len(data) > max_bytes:
                raise HTTPException(400, f"Файл «{name}» больше {settings.max_file_mb} МБ.")
            try:
                units = extract(name, data)
            except ExtractError as e:
                raise HTTPException(400, str(e)) from e
            chunks = chunk_units(units)
            vectors = client.embed([c.text for c in chunks])
            store.add_document(session, name, chunks, vectors)
            log.info("document indexed: %d units, %d chunks", len(units), len(chunks))
            added.append({"file": name, "chunks": len(chunks)})
        return {"added": added, "files": session.files}

    @app.post("/api/ask")
    def ask(body: AskIn, session: Session = Depends(current_session)):
        if session.questions >= settings.max_questions:
            raise HTTPException(400, f"Лимит {settings.max_questions} вопросов на сессию исчерпан.")
        try:
            result = rag_answer(client, session, body.question)
        except NoDocuments as e:
            raise HTTPException(400, "Сначала загрузите документы.") from e
        session.questions += 1
        return {"answer": result.text, "sources": [asdict(s) for s in result.sources]}

    @app.delete("/api/session")
    def delete_session(response: Response, sid: str | None = Cookie(default=None)):
        if sid:
            store.delete(sid)
        response.delete_cookie(COOKIE)
        return {"ok": True}

    return app


def build() -> FastAPI:
    logging.basicConfig(level=logging.INFO)
    return create_app(Settings())

- [ ] **Step 8: HTTPS-прокси**

Если на шаге 5 найден **nginx** — создать `/etc/nginx/sites-available/rag-demo` (подставить punycode):
```nginx
server {
    listen 80;
    server_name <punycode>;
    client_max_body_size 25m;
    location / {
        proxy_pass http://127.0.0.1:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 180s;
    }
}
```
```bash
ln -s /etc/nginx/sites-available/rag-demo /etc/nginx/sites-enabled/rag-demo && nginx -t && systemctl reload nginx
certbot --nginx -d <punycode>
```
Если найден **caddy** — добавить в Caddyfile блок `<punycode> { reverse_proxy 127.0.0.1:8090 \n request_body { max_size 25MB } }` и `systemctl reload caddy`.
Если ни то ни другое — остановиться и спросить Александра.
